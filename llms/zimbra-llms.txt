# Zimbra

> Zimbra is an open-source email and collaboration platform (email, calendar, contacts, tasks, chat, file storage, and an in-browser office suite) serving 200M+ users. It is self-hosted (on-premises, private cloud, or regional data center) for data sovereignty. Its programmatic interface is a SOAP API, wrapped by a first-party GraphQL/JS client. There is no public OpenAPI/REST contract.

## APIs
- [Zimbra SOAP API Reference](https://files.zimbra.com/docs/soap_api/): The canonical SOAP API reference (account, mail, admin namespaces).
- [SOAP API Reference Material (ZCS 8.0+)](https://wiki.zimbra.com/wiki/SOAP_API_Reference_Material_Beginning_with_ZCS_8.0): Wiki index of SOAP request/response documentation.

## SDKs & Packages
- [@zimbra/api-client (npm)](https://www.npmjs.com/package/@zimbra/api-client): Official JS + GraphQL client over the Zimbra SOAP API (BSD-3-Clause).
- [zm-api-js-client (GitHub)](https://github.com/Zimbra/zm-api-js-client): Source for the JS/GraphQL client.
- [zm-mailbox (GitHub)](https://github.com/Zimbra/zm-mailbox): Core mailbox / server component (Java, FOSS edition).
